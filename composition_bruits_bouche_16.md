# Composition "Bouche Orchestra" - 16 Instruments

## Configuration

- **BPM**: 120
- **Durée**: 1min30 (180 beats)
- **Grille**: 4x4 (16 positions)

---

## Les 16 Sons de Bouche

### Rangée 1 - Percussions

| Position | Nom          | Description                          | Rôle              |
| -------- | ------------ | ------------------------------------ | ----------------- |
| 0        | `kick`       | "Boom" grave avec les joues gonflées | Grosse caisse     |
| 1        | `snare`      | "Psh" sec, air entre les dents       | Caisse claire     |
| 2        | `hihat`      | "Tss" court et précis                | Charleston fermé  |
| 3        | `hihat-open` | "Tshhh" prolongé                     | Charleston ouvert |

### Rangée 2 - Clics & Clacs

| Position | Nom     | Description                           | Rôle             |
| -------- | ------- | ------------------------------------- | ---------------- |
| 4        | `click` | Claquement de langue contre le palais | Clic principal   |
| 5        | `clac`  | Claquement joue aspirée               | Percussion sèche |
| 6        | `pop`   | Lèvres qui éclatent (bouchon)         | Accent           |
| 7        | `toc`   | Langue contre les dents               | Tic-tac          |

### Rangée 3 - Souffles & Textures

| Position | Nom   | Description              | Rôle          |
| -------- | ----- | ------------------------ | ------------- |
| 8        | `pff` | Souffle d'exaspération   | Texture douce |
| 9        | `fff` | Air entre dents et lèvre | Bruit blanc   |
| 10       | `hhh` | Expiration chaude "Haaa" | Pad ambient   |
| 11       | `sss` | Sifflement doux prolongé | Nappe         |

### Rangée 4 - Effets Spéciaux

| Position | Nom     | Description                       | Rôle          |
| -------- | ------- | --------------------------------- | ------------- |
| 12       | `bwip`  | Glissando lèvres "Bwip"           | Effet montant |
| 13       | `prr`   | Roulement de langue/lèvres        | Roulement     |
| 14       | `gulp`  | Déglutition sonore                | Ponctuation   |
| 15       | `smack` | Baiser sonore / claquement lèvres | Accent final  |

---

## Structure de la Composition

```
INTRO      [0-16]    - Présentation progressive des instruments
VERSE 1    [16-48]   - Groove principal, tous les percussifs
BREAK 1    [48-64]   - Focus sur les textures et souffles
VERSE 2    [64-96]   - Groove enrichi, plus de clics
BUILD      [96-128]  - Montée en intensité
DROP       [128-160] - Tous les instruments, densité maximale
OUTRO      [160-180] - Déconstruction progressive
```

## Notes de Production

1. **Équilibre**: Chaque instrument a au minimum 8 occurrences, les percussifs principaux dominent naturellement
2. **Densité**: La section BUILD (96-128) atteint une densité maximale avec tous les 16 instruments actifs
3. **Respiration**: Le BREAK (48-64) offre une pause texturée avant la reprise
4. **Progression**: L'intensité monte graduellement jusqu'au DROP
5. **Variété**: Alternance entre sections percussives et texturées
